# Free vs. paid: Entra-native feature → our emulation

The tenant runs on **Entra ID Free** (target spend: $0). Where Microsoft sells a feature, we build the governance outcome in code and say so honestly. The "Evidence" column is filled in from `docs/capability-matrix.md` and a P2 trial.

| Entra-native feature | License | Our emulation | Evidence |
|---|---|---|---|
| Lifecycle Workflows | ID Governance | `nhigov lifecycle run` state machine : notices, holds, retirement soft-delete, `--as-of` for demos | Unit tests; live departing-sponsor run passed 2026-11-01 |
| Access reviews (for service principals) | P2 / ID Governance | `review_by` in registry + NHI-010 finding + GitHub issue to sponsor | |
| Entitlement management / access packages for agents | ID Governance / Agent 365 | Registry PR = access request; reconciler = provisioning | |
| Agent ID governance (sponsor automation, Agent 365 registry) | Agent 365 + P1 or M365 E7 | Sponsor is a required registry field; NHI-002 + lifecycle disables the NHI `sponsor_grace_days` after the sponsor's account is disabled, and `apply` keeps it off (hold) | Live 2026-11-01 |
| Certificate rotation for workload identities | (no native automation for app credentials) | `nhigov lifecycle rotate`: add the new key, verify a real token, then remove the old one (blueprints: provisioner PATCH, as addKey isn't usable for them; plain apps: self-service addKey/removeKey) | `bp-agent-router` rotated live 2026-11-01 |
| Conditional Access for workload identities | Workload ID Premium (not included in P2; separate trial) | Not emulated. Try it with a Workload ID Premium trial | |
| Graph activity logs (which Graph permission was used) | P1 + Log Analytics (paid) | **Not implemented.** L3 analysis on our own API instead: `nhigov usage analyze` (granted − used, scaled by cadence, NHI-012; ADR-007, ADR-013) | Live 2026-11-06: the deliberately over-granted demo agent was flagged; nothing else was |
| SP sign-in activity reports (dormancy) | Endpoint answers on Free, **data doesn't**: probe R10/R11 returned 200 (2026-10-31), but on 2026-11-08, after a week of real sign-ins (scanner, agents, GitHub Actions), both `servicePrincipalSignInActivities` and `appCredentialSignInActivities` returned 0 rows | Not available on Free; L3 usage log instead. Check whether the reports fill in under a premium licence | R10/R11 200 with 0 rows |
| Sign-in logs for service principals | **P1 confirmed** (probe R09: `Authentication_RequestFromNonPremiumTenantOrB2CTenant`) | L3 usage log; L2 only during the trial | R09 license required |
| App management policy (block secrets, cap cert lifetime) | Reportedly Free now (probe R12/W06) | Native: `nhigov lifecycle policy` merges passwordAddition + symmetricKeyAddition + asymmetricKeyLifetime P180D into the tenant default policy (reads as the scanner, writes as the provisioner). NHI-003/NHI-004 still detect anything older. | Learn's setup page lists no license (2026-11-01); this tenant already enforces a Microsoft-set identifier-URI restriction in the same policy. Write refused (403) for the provisioner (app-only) **and** for a Global Administrator (delegated), 2026-11-01: most likely licence-gated (historically Workload ID Premium), though Learn doesn't say so. Reading is free. On this tenant P7 is detected (NHI-003), not prevented. Retry if a Workload ID trial is ever available |
